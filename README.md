# BP 神经网络反向传播实验台

一个**零依赖的纯前端交互实验台**，用于直观理解神经网络的前向传播、反向传播与训练过程。你可以自由配置网络结构、激活函数、损失函数和优化器，逐环节查看每一步的数值推导，并通过传播全景图、决策边界、损失曲线与对照实验观察模型是如何学习的。

> 适合课程演示、大创项目展示与深度学习入门教学。**双击 `index.html` 即可运行**，无需安装任何依赖。

## 功能特性

### 核心实验台
- **网络结构**：输入层 / 输出层节点数自由设置（1–12），隐藏层最多 5 层、每层节点数独立可调
- **激活函数**：Sigmoid、Tanh、ReLU、Leaky ReLU、ELU、Linear、Softmax，逐层独立选择
- **损失函数**：MSE、MAE、Huber、BCE、CE；`Sigmoid+BCE` 与 `Softmax+CE` 自动启用解析化简 δ = a − t
- **训练参数**：学习率、循环次数、优化器（SGD / Momentum / Adam）、初始化方式、随机种子、梯度裁剪均可设置
- **参数编辑**：权重矩阵与偏置向量逐项手工修改；输入项与目标值用表格自由增删改
- **单步推导**：① 前向 → ② 反向 → ③ 应用更新，逐层列出 z、a、δ、∂L/∂W、∂L/∂b 与 ΔW

### 过程可视化
- **BP 传播全景**：整条链路一次铺开，输入 → 每层（上蓝前向 W/b/z/a，下橙反向 δ/∂W/ΔW）→ 损失 → 参数更新，层间双向流光箭头，每层独立卡片含权重与梯度热力图
- **逐环节演示**：把一次 BP 拆成 4L+3 个环节，支持时间轴跳转、自动播放（5 档速度）、键盘 ←/→/空格；动态网络图高亮当前层并实时显示数值
- **实时反馈**：网络结构 SVG（连线颜色/粗细表示权重）、损失收敛曲线（线性/对数纵轴）、逐轮日志、最终预测对比

### 拓展实验台
- **决策边界**：2D 输入平面的预测热力图，叠加训练样本，支持随训练演化与多阶段快照对比
- **函数曲线**：7 种激活 / 5 种损失的函数值与导数曲线，鼠标悬停读取精确取值
- **优化器对比**：同一数据、同一初始权重并排训练 SGD / Momentum / Adam，自动统计收敛速度
- **过拟合与正则**：带噪声回归任务，可调网络容量、L2 与 Dropout，双曲线展示过拟合及其缓解

## 快速开始

**方式一（推荐）**：直接双击 `index.html`，用任意现代浏览器打开即可。

**方式二**：如需通过 HTTP 访问，在项目目录执行：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

不需要 `npm install`，没有构建步骤，也不需要后端服务。

## 使用建议

1. **先看效果**：打开后默认载入 XOR 示例（2→3→1，Sigmoid + BCE），点击「开始训练」即可看到损失下降与预测收敛。
2. **再学原理**：用「逐环节演示」的自动播放完整走一遍前向与反向；点击「BP 传播全景」中的卡片可跳到对应环节。
3. **做对照实验**：切到下方「拓展实验台」，用决策边界看分界面如何形成，用优化器对比看三种优化器的收敛差异，用正则实验看 L2 / Dropout 如何压住过拟合。
4. **自由改造**：左侧下拉可一键切换 AND / OR / 线性拟合 / Softmax 三分类等预设；所有参数、权重、样本都可直接编辑；配置支持 JSON 导入导出。

## 算法实现说明

- **全批量梯度下降**：每轮用全部样本梯度的平均值更新一次参数。
- **输出层误差**：`Sigmoid+BCE`、`Softmax+CE` 使用解析化简 δ = a − t；Softmax 通用情形使用雅可比 `aᵢ(dᵢ − Σⱼaⱼdⱼ)`。
- **参数更新**：SGD / Momentum（μ=0.9）/ Adam（β₁=0.9, β₂=0.999，含偏差校正）。
- **数值稳定**：全局范数梯度裁剪、Softmax 减去最大值、损失函数的概率值裁剪。
- **正则化**：L2 权重衰减（正则项不随 batch 平均）与 inverted dropout（仅隐藏层，推理时期望不变）。

## 验证情况

- 对所有激活 × 损失组合做了**数值梯度检验**，解析梯度与数值梯度最大误差约 **1e-10**。
- XOR、AND、线性回归、Softmax 三分类均收敛到接近零误差。
- 浏览器端经过 DOM 级自动化测试：主流程、可视化、拓展实验、极端网络结构（12 输入 / 5 隐藏层 / 12 输出）均通过。
