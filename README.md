# BP 神经网络反向传播实验台

一个用于教学和演示的交互式神经网络实验台，纯浏览器运行，不依赖任何第三方库。可以在界面上改动网络结构、激活函数、损失函数、优化器和训练数据，逐步观察前向传播、误差反传与参数更新的中间数值，并用图形看到模型如何收敛。

在线演示：https://sinianhai181-png.github.io/bp-neural-network-lab/

## 运行

直接双击 `index.html` 用现代浏览器打开即可，无需安装、构建或后端服务。

若浏览器对本地文件有限制，可在项目目录起一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。

程序本身零依赖。只有运行自动化测试才需要 Node.js：

```bash
npm install
npm test
```

## 能做什么

**配置与训练**

- 输入层、输出层节点数 1–12 可调；隐藏层最多 5 层，每层宽度独立设置
- 激活函数：Sigmoid、Tanh、ReLU、Leaky ReLU、ELU、Linear、Softmax，逐层选择
- 损失函数：MSE、MAE、Huber、BCE、CE
- 优化器：SGD、Momentum、Adam；另有学习率、训练轮数、初始化方式、随机种子、梯度裁剪阈值
- 权重矩阵和偏置向量可逐项手工改写，训练样本可增删

**过程观察**

- 单步模式按「前向 → 反向 → 应用更新」三段推进，逐层列出 z、a、δ、∂L/∂W、∂L/∂b 与 ΔW
- 传播全景把整条链路铺在一张图里，每个层卡片上半部是前向量（W、b、z、a），下半部是反向量（δ、∂W、ΔW）
- 逐环节演示把一次传播拆成 4L+3 步，可自动播放或拖动时间轴，键盘左右方向键切换、空格暂停
- 网络结构图用连线颜色区分权重正负、粗细表示幅值；损失曲线支持线性和对数纵轴

**对照实验**

- 决策边界：2D 输入平面上逐点预测并着色，叠加样本点，可保存多个训练阶段的快照
- 函数曲线：各激活/损失的函数值与导数曲线，鼠标悬停读取具体数值
- 优化器对比：同一数据、同一初始权重下并排训练 SGD / Momentum / Adam
- 过拟合与正则：带噪声的回归任务，可调网络容量、L2 系数和 Dropout 率，对比训练/验证损失

## 实现要点

- 训练方式全批量为默认：每轮用全部样本梯度的均值更新一次参数。这是为了教学时数值可核对，不是小批量 SGD。
- 输出层误差分两条路径：`Sigmoid+BCE` 和 `Softmax+CE` 用解析化简 δ = a − t；一般情形按链式法则计算，Softmax 使用雅可比形式 `aᵢ(δᵢⱼ − aⱼ)` 化简后的结果。
- 优化器实现了带动量的 SGD 和 Adam（β₁=0.9, β₂=0.999，含偏差校正）。
- 数值稳定措施包括：梯度全局范数裁剪、Softmax 减去最大值、概率裁剪到 [EPS, 1−EPS]（EPS=1e−9）。
- 正则项只在「对照实验」里启用，默认关闭：L2 按标准约定加在平均数据损失上（不随 batch 再平均），Dropout 采用 inverted 形式，仅作用于隐藏层。

需要把计算引擎单独用于 Node 时：

```js
const { Network } = require('./js/engine.js');
const net = new Network({ sizes: [2, 3, 1], activations: ['sigmoid', 'sigmoid'], loss: 'bce' });
```

## 验证

测试位于 `tests/`，`npm test` 一次跑完全部 6 组。

**梯度正确性**：在 21 组语义有效的激活/损失搭配上做中心差分数值梯度检验，逐项比较 ∂L/∂W 与 ∂L/∂b，最大绝对误差 7.2e−10。MSE、MAE、Huber 各遍历 6 种输出激活，BCE 配 Sigmoid，CE 和 MSE 各配 Softmax（覆盖通用雅可比路径）。此外单独检验了固定 mask 的 Dropout 梯度和 L2 正则梯度。

MAE 与 Huber 在误差恰好为 0 处不可导，检验样本避开了该点。BCE 的导数要求输出落在 (0,1)，因此在非 Sigmoid 输出层下它只是可计算、不代表合理的模型配置，界面会给出提示，梯度检验也不覆盖这类搭配。

**收敛性**：用固定随机种子实测，结果可复现。

| 任务 | 配置 | 轮数 | 初始损失 → 最终损失 |
| --- | --- | --- | --- |
| XOR | 2-3-1 Sigmoid+BCE，η=0.8，SGD，seed=3 | 1500 | 0.7469 → 0.0122 |
| AND | 2-3-1 Sigmoid+BCE，η=0.5，SGD，seed=5 | 1200 | 0.9350 → 0.0070 |
| 线性回归 y=2x+1 | 1-1 Linear+MSE，η=0.05，SGD，seed=9 | 800 | → 0.0000（预测 1/3/5/7） |
| 三分类 one-hot | 2-5-3 Tanh+Softmax+CE，η=0.05，Adam，seed=11 | 800 | 1.0757 → 0.0001 |

四个任务在训练集上均达到 100% 分类准确率或近似零回归误差。这是训练集指标，不反映泛化能力；泛化行为用「过拟合与正则」实验单独观察。

**其他测试**：浏览器 DOM 级回归覆盖界面交互、单步与自动训练、结构变更、配置导入导出；极端结构（12 输入 / 5 隐藏层 / 12 输出）和播放器滚动行为有专门用例。

## 已知限制

- 训练集与验证集只在「过拟合与正则」实验内划分，主实验台使用的是全批量训练，没有小批量与 epoch 级别的早停。
- 决策边界依赖二维输入，输入层不是 2 维时该实验只给出提示，不绘制。
- 逐环节演示按单个样本展开；自动训练按全体样本更新，两者数值不会完全一致，推导面板中已注明。
- 没有持久化用户配置到服务器的机制，刷新页面会回到默认示例。配置可用 JSON 手动导出/导入。
