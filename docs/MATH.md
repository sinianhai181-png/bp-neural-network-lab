# 数学推导

这份文档说明 `js/engine.js` 里每一步计算对应什么公式。符号和代码变量一一对应，可以直接对照源码阅读。

## 符号约定

设网络共 L 层（不含输入层），第 k 层的神经元数为 nₖ：

- 输入 x ∈ ℝⁿ⁰，目标 t ∈ ℝⁿᴸ
- 第 k 层的加权和 z⁽ᵏ⁾ ∈ ℝⁿᵏ，激活值 a⁽ᵏ⁾ ∈ ℝⁿᵏ，并约定 a⁽⁰⁾ = x
- 第 k 层的权重 W⁽ᵏ⁾ ∈ ℝⁿᵏˣⁿᵏ⁻¹，偏置 b⁽ᵏ⁾ ∈ ℝⁿᵏ（k = 1…L）
- W⁽ᵏ⁾ⱼᵢ 表示从第 k−1 层第 i 个神经元到第 k 层第 j 个神经元的权重
- 误差信号 δ⁽ᵏ⁾ = ∂L/∂z⁽ᵏ⁾，梯度 ∂L/∂W⁽ᵏ⁾ⱼᵢ 与 ∂L/∂b⁽ᵏ⁾ⱼ

代码里 `sizes[k]` 即 nₖ，`weights[k][j][i]` 即 W⁽ᵏ⁺¹⁾ⱼᵢ（下标从 0 开始），`deltas[k]` 即 δ⁽ᵏ⁾。

## 前向传播

对第 k 层（k = 1…L）：

```
z⁽ᵏ⁾ⱼ = Σᵢ W⁽ᵏ⁾ⱼᵢ · a⁽ᵏ⁻¹⁾ᵢ + b⁽ᵏ⁾ⱼ
a⁽ᵏ⁾  = fₖ(z⁽ᵏ⁾)
```

`forward()` 逐层算出 z 和 a 并缓存下来，反向传播要复用这些中间量。Softmax 层对整个 z 向量归一化，不是逐元素激活。

## 激活函数与导数

| 名称 | f(z) | f′(z) |
| --- | --- | --- |
| Sigmoid | 1 / (1 + e⁻ᶻ) | a(1 − a) |
| Tanh | (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ) | 1 − a² |
| ReLU | max(0, z) | 1 (z > 0)，否则 0 |
| Leaky ReLU | z (z > 0)，否则 0.01z | 1 (z > 0)，否则 0.01 |
| ELU | z (z > 0)，否则 eᶻ − 1 | 1 (z > 0)，否则 a + 1 |
| Linear | z | 1 |

Sigmoid 与 Tanh 的导数写成 a 的形式，是因为 a 已在前向时算好，直接复用既快又稳定。ELU 在 z ≤ 0 时 a = eᶻ − 1，故 eᶻ = a + 1，导数即 a + 1。

**Softmax** 单独处理。设 aᵢ = eᶻⁱ / Σⱼeᶻʲ，其雅可比矩阵为：

```
∂aᵢ/∂zⱼ = aᵢ(δᵢⱼ − aⱼ)
```

其中 δᵢⱼ 是 Kronecker delta。数值实现先减去 max(z) 再取指数，避免溢出；分母加了 EPS 防止除零。

## 损失函数与导数

记 a 为网络输出，t 为目标，n 为输出维度。

**MSE**（回归常用）
```
L = ½ Σᵢ (aᵢ − tᵢ)²          ∂L/∂aᵢ = aᵢ − tᵢ
```
系数 ½ 是为了求导后抵消平方产生的 2。

**MAE**
```
L = Σᵢ |aᵢ − tᵢ|             ∂L/∂aᵢ = sign(aᵢ − tᵢ)
```
在 aᵢ = tᵢ 处不可导，代码里该点返回 0。数值梯度检验避开了这些点。

**Huber**（δ = 1）
```
          ½ rᵢ²        rᵢ ≤ 1
L = Σᵢ {                          rᵢ = |aᵢ − tᵢ|
          rᵢ − ½        rᵢ > 1

∂L/∂aᵢ = clamp(aᵢ − tᵢ, −1, 1)
```
小误差时是平方、大误差时是线性，兼顾 MSE 的平滑与 MAE 的抗离群。

**BCE**（配 Sigmoid 输出）
```
L = −Σᵢ [tᵢ ln aᵢ + (1 − tᵢ) ln(1 − aᵢ)]
∂L/∂aᵢ = (aᵢ − tᵢ) / [aᵢ(1 − aᵢ)]
```
aᵢ 会被裁剪到 [EPS, 1 − EPS]，避免 ln(0)。

**CE**（配 Softmax 输出）
```
L = −Σᵢ tᵢ ln aᵢ            ∂L/∂aᵢ = −tᵢ / aᵢ
```
t 通常取 one-hot。

## 输出层误差 δ⁽ᴸ⁾

一般情形按链式法则：

```
δ⁽ᴸ⁾ᵢ = (∂L/∂a⁽ᴸ⁾ᵢ) · f′ₗ(z⁽ᴸ⁾ᵢ)
```

Softmax 输出时要把雅可比乘进去：

```
δ⁽ᴸ⁾ᵢ = Σⱼ (∂L/∂aⱼ) · (∂aⱼ/∂zᵢ)
       = Σⱼ dⱼ · aⱼ(δⱼᵢ − aᵢ)
       = aᵢ · dᵢ − aᵢ · Σⱼ aⱼdⱼ
       = aᵢ (dᵢ − Σⱼ aⱼ dⱼ)
```

这正是代码里 `dot = Σ a[i]·d[i]`、然后 `δᵢ = aᵢ(dᵢ − dot)` 的来源。注意求和下标从 j 换到 i 时用到了雅可比的对称性。

### 两个解析化简

**Sigmoid + BCE**：把 ∂L/∂a = (a − t)/(a(1 − a)) 与 f′(z) = a(1 − a) 相乘，分母约掉：

```
δ⁽ᴸ⁾ = a − t
```

**Softmax + CE**：把 ∂L/∂aⱼ = −tⱼ/aⱼ 代入上式：

```
δ⁽ᴸ⁾ᵢ = aᵢ(−tᵢ/aᵢ − Σⱼ aⱼ·(−tⱼ/aⱼ))
       = aᵢ(−tᵢ + Σⱼ tⱼ)
       = aᵢ − tᵢ            （因 one-hot 目标 Σ tⱼ = 1）
```

两种化简都写成 `a − t`，代码里由 `isPaired()` 判断启用。它们数值更稳定（不会除以很小的 a），也是教材里的标准写法。

## 隐藏层误差 δ⁽ᵏ⁾

从第 k+1 层往回推：

```
δ⁽ᵏ⁾ᵢ = (Σⱼ W⁽ᵏ⁺¹⁾ⱼᵢ · δ⁽ᵏ⁺¹⁾ⱼ) · f′ₖ(z⁽ᵏ⁾ᵢ)
```

先按权重把下一层的误差加权求和（相当于用 Wᵀ 乘），再乘本层激活的导数。这就是反向传播名字的由来：`backward()` 从 l = L−1 循环到 1。

若启用了 inverted dropout，隐藏层激活为 a = f(z)·m/keep，因此 ∂a/∂z = f′(z)·m/keep，上式要再乘这个因子。代码里的 `factor = mk[i] / keep` 就是它。

## 参数梯度

由 δ 的定义直接得到：

```
∂L/∂W⁽ᵏ⁾ⱼᵢ = δ⁽ᵏ⁾ⱼ · a⁽ᵏ⁻¹⁾ᵢ      （外积）
∂L/∂b⁽ᵏ⁾ⱼ   = δ⁽ᵏ⁾ⱼ
```

`backward()` 最后那段双重循环就是在算这个外积。

## 批量平均与正则

`accumulate()` 遍历 N 个样本，把各自的梯度累加后除以 N：

```
∂L/∂W = (1/N) Σₙ ∂Lₙ/∂W
```

L2 正则项采纳标准约定——加在平均数据损失上、不再除以 N：

```
L_total = (1/N) Σₙ Lₙ + (λ/2) Σₖ Σⱼ Σᵢ (W⁽ᵏ⁾ⱼᵢ)²
∂L_total/∂W⁽ᵏ⁾ⱼᵢ = (1/N) Σₙ ∂Lₙ/∂W⁽ᵏ⁾ⱼᵢ + λ W⁽ᵏ⁾ⱼᵢ
```

偏置不加正则。代码里这一项直接加在除以 N 之后的梯度上。

**Inverted dropout**：训练时以概率 p 把隐藏单元置零，并把保留的激活放大 1/(1−p) 倍：

```
a = f(z) · m / (1 − p),    m ~ Bernoulli(1 − p)
```

这样 a 的期望仍是 f(z)，推理时无需再缩放。`forward()` 里把 mask 存进 cache，`backward()` 用它保证梯度与前向一致。

## 梯度裁剪

`clipGradients()` 实现全局范数裁剪。把所有梯度拼成一个向量 g，若其 L2 范数超过阈值 c：

```
g ← g · c / ‖g‖
```

方向不变、长度受限，避免 ReLU 或交叉熵组合下的梯度爆炸。

## 优化器

记学习率为 η，第 t 次的梯度为 gₜ。

**SGD**
```
θₜ₊₁ = θₜ − η gₜ
```

**Momentum**（μ = 0.9）
```
vₜ = μ vₜ₋₁ − η gₜ
θₜ₊₁ = θₜ + vₜ
```

**Adam**（β₁ = 0.9, β₂ = 0.999, ε = 1e−8）
```
mₜ = β₁ mₜ₋₁ + (1 − β₁) gₜ
vₜ = β₂ vₜ₋₁ + (1 − β₂) gₜ²
m̂ₜ = mₜ / (1 − β₁ᵗ)          ← 偏差校正
v̂ₜ = vₜ / (1 − β₂ᵗ)
θₜ₊₁ = θₜ − η · m̂ₜ / (√v̂ₜ + ε)
```

初始 m₀ = v₀ = 0，前几步的估计偏小，除以 (1 − βᵗ) 校正。代码里 `this.t` 从 0 开始、`apply()` 开头先自增，所以第一次更新时 t = 1。

## 数值梯度检验

`tests/engine.test.js` 用中心差分验证解析梯度：

```
(g(z + h) − g(z − h)) / (2h) ≈ ∂L/∂z
```

h = 1e−6。检验覆盖 21 组语义有效的激活/损失搭配，最大绝对误差约 7e−10。BCE 只在 Sigmoid 输出下检验、CE 只在 Softmax 输出下检验，因为这两种损失的导数公式依赖对应的输出范围。
