数学原理与公式速查（点击展开）

前向传播

对第 l 层（l = 1 … L）：

z⁽ˡ⁾ = W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = fₗ( z⁽ˡ⁾ ),        a⁽⁰⁾ = x
L = E( a⁽ᴸ⁾, t )

反向传播

输出层:  δ⁽ᴸ⁾ = ∂L/∂a⁽ᴸ⁾ ⊙ f′(z⁽ᴸ⁾)
隐藏层:  δ⁽ˡ⁾ = ( W⁽ˡ⁺¹⁾ᵀ · δ⁽ˡ⁺¹⁾ ) ⊙ f′(z⁽ˡ⁾)
梯度:    ∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ · (a⁽ˡ⁻¹⁾)ᵀ ,   ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾
更新:    W ← W − η · ∂L/∂W ,   b ← b − η · ∂L/∂b

当输出层为 Sigmoid + BCE 或 Softmax + CE 时，输出层误差信号可解析化简为 δ⁽ᴸ⁾ = a − t，本实验台会自动启用该化简（数值更稳定）。Softmax 的通用情形使用雅可比矩阵 Jᵀ·d = aᵢ(dᵢ − Σⱼaⱼdⱼ)。

推荐搭配

  • 二分类：Sigmoid（输出层）+ BCE
  • 多分类：Softmax（输出层）+ CE，目标用 one-hot
  • 回归：Linear（输出层）+ MSE / MAE / Huber
  • 隐藏层常用 ReLU / Tanh；配合 ReLU 可用 He 初始化

说明：本实验台采用全批量梯度下降，每轮用全部样本梯度的平均值更新一次参数；优化器可选 SGD / Momentum / Adam。
